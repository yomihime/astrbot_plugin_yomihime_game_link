# FF14 当前能力与验收边界

本表概述当前 FF14 模块的功能和验收边界。插件更新不要求为 alpha 阶段统一清库或重装；具体存储迁移只按[凭据与存储合同](credential-storage.md)列出的条件执行。构建和运行时验收按对应源码与环境核验；历史提交不是当前验收记录。

| 能力 | 当前入口与条件 | 尚需本地验证 |
| --- | --- | --- |
| 帮助与状态 | `/ygl help`、`/ygl ff14 help`、子命令 `help`、`status`；文字和共用图片渲染 | 目标平台实际图片呈现 |
| 物品 | 命令、统一模块页、宿主工具；名称/ID、歧义候选、来源及缺项 | 真实来源与模型/IM 链路 |
| 市场 | 命令、统一模块页、宿主工具；保留区域、范围、品质及意图，挂牌样本有限 | 真实 Universalis 响应与跨轮选择 |
| 公开角色 Logs | 命令、统一模块页、宿主工具；按国服/国际服分别配置 OAuth 凭据 | 实际管理员密钥环境、来源认证及角色结果 |
| 日历 | 命令、统一模块页；后台本地快照同步与来源状态 | 真实日历更新、时区/每日窗口和实际投递 |
| 订阅 | 本人私聊显式创建、分页、revision 更新与取消；暂停保留数据 | QQ/NapCat 或目标平台的真实定时投递 |
| 设置与凭据 | 登录后的插件设置页；当前值校验、CAS、加密状态枚举与授权修复 | 真实浏览器焦点/键盘/窄屏及反向代理 |

统计网页 `output` 不注册；私人报告、账号绑定和其它游戏不在当前公开能力范围。退役 FF14 定位页已删除；旧配置读取和存储迁移边界见[配置架构](code-architecture.md)与[存储合同](credential-storage.md)。无 FFLogs 凭据不应阻止无需凭据的能力启动。

真实宿主 smoke 的可复现范围和限制见[测试入口](real-host-smoke.md)。它是隔离环境验证，不能代替真实上游、浏览器或平台消息验收。

模块配置、默认区域和页面合同见[模块维护指南](module-maintainer-guide.md)、[当前代码分层](code-architecture.md)与[管理设置说明](management-home-settings.md)。
