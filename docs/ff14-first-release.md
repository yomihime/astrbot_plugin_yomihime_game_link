# FF14 当前能力与验收边界

本表适用于当前 fresh-install alpha 设计。构建工件和回归结果需按具体提交核验；[历史验收快照](history/ff14-first-release.md)不能证明本次代码已部署。

| 能力 | 当前入口与条件 | 尚需本地验证 |
| --- | --- | --- |
| 帮助与状态 | `/ygl help`、`/ygl ff14 help`、子命令 `help`、`status`；文字和共用图片渲染 | 目标 Windows 字体及实际 IM 图片发送 |
| 物品 | 命令、统一模块页、宿主工具；名称/ID、歧义候选、来源及缺项 | 真实来源与模型/IM 链路 |
| 市场 | 命令、统一模块页、宿主工具；保留区域、范围、品质及意图，挂牌样本有限 | 真实 Universalis 响应与跨轮选择 |
| 公开角色 Logs | 命令、统一模块页、宿主工具；按国服/国际服分别配置 OAuth 凭据 | 实际管理员密钥环境、来源认证及角色结果 |
| 日历 | 命令、统一模块页；后台本地快照同步与来源状态 | 真实日历更新、时区/每日窗口和实际投递 |
| 订阅 | 本人私聊显式创建、分页、revision 更新与取消；暂停保留数据 | QQ/NapCat 或目标平台的真实定时投递 |
| 设置与凭据 | 登录后的插件设置页；当前值校验、CAS、加密状态枚举与授权修复 | 真实浏览器焦点/键盘/窄屏及反向代理 |

统计网页 `output` 不注册；私人报告、账号绑定和其它游戏不在本次范围。退役 FF14 定位页及旧配置迁移入口已删除。无 FFLogs 凭据不阻止 Core、帮助和其它非凭据能力启动。

云中真实 AstrBot 4.29.1 验证使用官方源码与实际 ZIP，在离线防护下安装并启动 Core/FF14、检查鉴权/视图资源、渲染帮助 PNG 和关闭宿主；没有提供真实用户凭据、调用付费模型或执行生产消息投递。[复现入口](real-host-smoke.md)明确区分真实宿主路径、固定夹具和被拒绝的公开日历 HTTP。

完整清理范围、Windows 资格与后续验证见[交接说明](alpha-cleanup-handoff.md)。
