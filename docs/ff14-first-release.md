旧 `ff14` 页面仍服务 Logs、日历及已有链接，不能在等价替代完成前删除。模块配置、缓存、密钥和业务数据具有稳定 module_id 所有权；当前 SQLite 仍共享，模块卸载不删除持久数据。本批不迁移真实数据，也不实现任意包热替换。

## 本批切片

- S1：帮助层级及恢复指引。
- S2：直接回复、有限样本及价格/时间事实的表达。
- S3：FF14 配置归属和安全 FFLogs 管理接线。
- S4：模块来源、凭据表单、公开投影及迁移映射归属模块；Host 消费显式受审的不可变装配，保持准入、授权、清理及共享持久数据边界。
- S5：直接相关清理、维护者说明及本地目录清理建议。

S2 的确定性回复保留标题、对象内容及来源，移除固定结构标签。价格保留原有效数值，与可信服务器名关联；最低价限定为本次返回的数据。World 上传、挂牌来源最近审核与接口获取时间分别标注，未知不互相代替。工具事实未增加节点，四区 all 的 min/overview 及缺值压力保持既有 512-node 门槛以内。隔离浏览器检查了合成 Core 投影的七种结果、亮暗主题、窄屏长内容、键盘提交、重复提交抑制、停止展示和迟到结果；这不是新版本真实行情或模型回答验收。

S3 将凭据管理与普通四字段管理分开，普通回退/恢复不获得秘密字段权限。国服、国际服分别提供空白掩码输入和保留/更新/清除；保存只证明已加密保存、上游未验证。凭据缺失、状态未知、不可使用、认证拒绝、限流、超时和上游失败不再一律称为未配置。相关扩展回归 190 项中 189 通过、1 项既有 Windows 符号链接跳过；最终集中修复后受影响 Python 41 项、管理页 35 项通过，独审无 Blocker/Important。正式构建资源的模拟浏览器验证了亮暗、320/390 窄屏、键盘、保存期间新草稿、清除、冲突、失败恢复和迟到失效；没有使用真实凭据或验证真实 OAuth。

各片通过相关测试、独立审查和构建后分别提交。最终跨层回归和真实验收范围按实际结果更新；不以历史通过替代新版本验证。

S4 的装配声明、纯支持和旧页唯一源码归 FF14；旧页仍投影到已有发布路径。声明与 fingerprint 只证明选定输入一致性，不是授权或任意包信任。相关回归 143 项中 136 通过、7 项平台跳过，Runtime 41 项及实际迁移输入调用者 6 项通过；最终修复后的相关检查 62 项中 59 通过、3 项既有 Windows 符号链接权限跳过，页面测试 45 项通过，独审无 Blocker/Important。隔离浏览器使用正式包、固定宿主资源重写和模拟 bridge：跨 460.9 秒同模块切页没有新增资产或业务请求，模拟卸载清理样式与视图、正式重开恢复；不等于真实后端卸载或新版本真实鉴权验收。

旧模块装配数据的重复 Host 表及重复凭据表单已退出，配置兼容函数归模块；旧 Host 配置文件仅留弃用标记。Host 仍显式选择内置受审 FF14 包、保留固定公开物理路由，运维命令仍有固定部署身份。这些是剩余耦合；第二个生产包接入及旧页退役尚需专门的兼容与真实宿主验收。
