## 数据与实现边界

- 物品描述允许经限制和控制字符检查的换行，首行与补充说明分层。食用效果只读取匹配物品身份的源数据，分别显示普通／高品质百分比与上限，缺值不推算。配方 ID、产量与材料继续来自源数据；任务仅标为“关联任务”，不推断奖励或提交条件。
- 新食用效果用于显式命令卡片及文字回退；现有 LLM facts 白名单未扩展，不应宣称模型已获得新增食物字段。
- 日历使用请求时刻、查询时区与实际返回事件动态计算日期、状态和截止时间，保留来源、部分结果、解释与时效提示。不得把预览中的日期、活动或过期数据硬编码进生产。全天事件按源数据的排他结束日显示最后一天。
- 状态卡表示已接入能力与使用条件，不是实时健康／凭据探测；默认采集间隔为 15 分钟，订阅可能延迟，不承诺准点送达。
- 帮助与结果卡是生产声明式实现，不要求与概念图像素一致。真实外部数据可能缺字段；缺失、部分结果和无数据场景必须保留诚实提示。
