# Dota 2 · 模块占位

> 状态：`blocked_reference`，当前不设计、不实现。

Dota 2 参考插件仍在开发中。为避免基于不稳定实现冻结错误的来源、字段、命令和跨 Steam 接口，本模块暂时留空。

当前只确定：

- 未来统一入口使用 `/ygl dota2 ...`。
- 模块目录预留为 `modules/dota2/`，当前禁止创建生产代码。
- 模块必须遵守主体公共接口，不直接访问数据库、渲染或发送消息。
- 账号与订阅管理必须使用命令；其他交互策略在重新设计时确认。

重新开始设计前必须具备：

1. 参考插件的稳定版本或明确接口说明。
2. 可核实的数据来源、认证方式、许可证和代码复用范围。
3. 主体已经通过 Core Ready Gate。
4. 对需求范围、Steam 可选依赖、公开/私人数据及订阅能力重新评估。
5. 新的模块设计和独立任务卡经过审查。

执行状态与恢复条件见 Dota 2 任务占位（历史记录未随库提供）。旧的 Dota 2 设计内容不再作为实现依据。
