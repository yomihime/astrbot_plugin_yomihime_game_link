# 命令展示设计

本设计说明命令回复、LLM facts、通用渲染和平台发送的职责。当前版本、构建与验收入口以[模块 SDK](../module-sdk.md)、[开发指南](../../CONTRIBUTING.md)和[文档索引](../README.md)为准；本文不记录候选摘要或实例操作步骤。

## 同一事实，两种输出

人类命令使用短标题“游戏连结 · 模块展示名 · 功能”；总帮助使用完整品牌名。正文先说明结果，再写必要限制和可执行的下一步。短开场或短句只改变文风，不能改变状态、事实或承诺排队、自动重试和必达。

LLM 工具仅返回简洁、稳定的结构化 facts，不带品牌、人格语句、随机短句、图片或需 OCR 的内容。数值保持语义类型；未知用 `null` 并说明缺失范围，不能补成零。业务来源、范围与事实由模块构造，人类展示的格式化不能回写原始 facts。

错误输出遵循 SDK 的 `{status, error[, supplement]}` 合同，`error` 与公开错误 DTO 完全一致。不得透传异常正文、响应头、秘密或原始上游内容。通用接收预算见[SDK 合同](../module-sdk.md)。

## 通用图片

Core presentation 负责测量、换行、字体、主题、素材校验、限额和 PNG 编码；模块提交展示结构与业务语义。Host 负责渠道能力、授权资源、单次发送和提交状态。SDK 只提供与平台无关的数据声明，不持有游戏逻辑、图片解码或宿主管理 API。

模块保留内容顺序、数值含义、评价映射和来源日期。缺失、失败、未查询和成功空结果分开表达。图片不能比文本来源包含更少的必要事实；超限或渲染失败必须在发送开始前用同一结果确定性回退为完整文本。发送后状态不确定时保持 `UNKNOWN`，不能自动补发图片或文本。

主题由 Core 提供通用默认和选项；模块可继承 Core 或声明受限覆盖。主题不能改变事实。模块徽标只从可信 manifest 声明的固定资源读取，不接受任意文件路径、URL 或 SVG 输入。

## FFLogs 语义

FFLogs 的分区、来源范围、百分位、角色职业和记录选择属于 FF14 模块。选优保留获胜整行并基于原始 Decimal；记录版本表示统计分区，不冒充精确击杀补丁。来源失败、隐藏、未查和无记录分开表达。不得按名称相似度、未经验证的翻译或人工名单连接数据。展示细节见[模块展示样式规范](module-display-style-spec.md)和[FFLogs 表格合同](../fflogs-table-presentation.md)。

## 来源、许可与验证

通用布局样例是离线 fixture。它不证明数据来源、实际安装、Host 页面、浏览器呈现或 IM 投递。字体和图标保留各自许可、版权说明与来源文件；不能因它们出现在同一张图片而合并授权。
