# FFLogs 查询边界

FFLogs 请求、地区选择、目录解析、缓存身份和排名事实属于 FF14 模块。命令、页面和绘图层只接收模块产生的已校验结果；通用 Core 不解释 FFLogs 字段，也不代理任意 GraphQL 请求。来源与授权声明见 [`modules/ff14/assembly.json`](../../modules/ff14/assembly.json)，模块实现见 [`modules/ff14/features/fflogs.py`](../../modules/ff14/features/fflogs.py) 与相邻目录、解析器代码。

国服和国际服是独立来源。请求使用已配置的对应地区凭据，不把地区、角色、目录或缓存结果相互替代。目录缺失、请求失败、无成绩和未查询是不同状态；部分范围不得描述为完整历史成绩。保存配置只表示本地配置已保存，不证明上游认证或角色查询成功。

公开角色 Logs 与输出统计是不同能力。当前 `output` 指令及统计页面未启用；角色查询成功不能作为统计能力已交付的证据。表格的范围、分区和字段表达规则见 [FFLogs 表格合同](../fflogs-table-presentation.md)。

数据预算、请求身份、生命周期和事实完整性以当前 FF14 实现及模块 SDK 合同为准。历史探查记录和阶段验收保存在 Git 历史中，不作为当前操作步骤或通过状态。
