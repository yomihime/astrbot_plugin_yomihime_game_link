# 管理页面与全局设置

唯一正式页面根为 `00-game-link`。首页提供模块入口；模块管理负责加载、恢复和受限普通配置维护；全局设置负责 Core 默认主题、字体、凭据存储与主密钥生命周期。模块主页、配置和辅助查询按受信 role 注册，详见 [前端合同](frontend-module-contract.md)。旧 shell/management 链接须从宿主详情重新打开，不转移、复用或续签旧 token。

普通设置当前值与草稿分开。保存携带精确 owner 与 revision/CAS，重复保存互斥。取消或放弃不写入；切页保留普通草稿、清除秘密草稿并围栏迟到响应。授权失效撤销秘密草稿、确认与旧回执，重新进入接受当前授权下的新读取。模块卸载或 epoch 改变后旧资源失效。

管理读取失败时清除当前上下文全部秘密草稿，包括 FF14 两区凭据、全局恢复密钥输入及已取得写回执后的读取失败；普通草稿保留。字体管理读取失败也清理当前全局秘密，并取消尚未提交的恢复确认，不能只清输入框而保留可提交的秘密意图。只有精确分类的授权拒绝显示授权失效，未知读取仍显示未确认；主密钥状态读取失败也不能显示刷新成功。写回执不等于已核实快照，UNKNOWN 写入不自动重发。清理与回执处理先核当前 owner、运行身份和页面生命周期，旧请求不能清除新上下文的输入、确认或替换新会话的状态。

storage_security 描述私密边界，ready 描述加密库存就绪，configured 描述已保存，decryptable 描述可解密；这些均不代表上游成功。正常 ready 将恢复及全域重配收在高级区；旧数据可用时不要求重新填写业务凭据。恢复原密钥、全域重配、环境密钥转托管和清除凭据均绑定页面内确认；取消、切页、刷新或授权变化使确认失效。迁移只提供只读计划，没有页面执行按钮。全域重配是逻辑失效，不宣称密码学擦除。

环境转托管复用当前可解密密钥，只提交 CAS，无需重填。环境变量由部署者移除后冷重启；刷新不会改变进程环境。旧布局只读取无路径、无秘密的迁移计划；计划说明源保留，不能称为已迁移。CLI 同样只支持 plan；后端 execute API 保留安全拒绝路径并返回 `requires_stopped_host`，当前没有生产旧库 adapter。支持范围见[存储迁移监督](storage-migration-supervision.md)，不能手填密钥绕过 guard。若存储状态为 blocked/unknown，库存数量和摘要、环境变量状态均不可观察；修正运行身份或访问条件后，正常冷重启同一 Host。不要清 selector、改真实 ACL、重填密钥或改用新库。

请求层 `management-requests.js`、合同校验 `management-contract.js`、状态控制 `management.js`、视图 `management-view.ts` 分开组织。Module 只消费独立公开服务。紧凑视觉和共用组件沿用 [UI规范](ui-guidelines.md)。离线测试、真实浏览器、Host、实际 IM 分别验收，代码支持不证明实例已安装或真实迁移成功。
