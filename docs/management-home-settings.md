# 管理首页与设置

默认 monitor 进入管理首页；聊天命令与 LLM 工具仍是业务主入口。
首页展示正式管理模块快照，普通设置状态来自获授权的配置目录与读取结果。
“普通设置已校验”只说明这些字段有效，不证明凭据、上游或模块全部能力可用。
读失败或无权限时显示未核对；刷新状态只读取，不执行恢复或业务查询。

模块名称按 locale 精确匹配、主语言、默认名称、内部 owner 回退。
同名碰撞附稳定 owner；名称不改变命令 `/ygl ff14`、授权、配置或数据归属。
全局设置始终可进入；模块设置与全局设置选中状态互斥。
普通字段显示当前值，编辑后保存或放弃；指定字段恢复默认形成 clear 草稿，
保存时仍使用精确 owner 和 revision/CAS。凭据使用独立状态、更新及确认清除接口。
高级维护保留受限迁移修复；没有通用缓存或业务数据删除按钮。

公共壳显式持有字体与行高，各应用禁用 Naive 全局 preflight，避免首次挂载设置
在壳样式之后插入全局 body 规则。模块应用已有禁用配置，继续保留。

首次进入辅助查询时，宿主 HTML 的未加载资源 URL 可能已过期；默认首页让这种
情况更常见。加载失败仅隔离相应 owner，提示从宿主正常 monitor 入口重开。
不自动重试、不续 token、不延长 TTL，也不在首页隐式加载模块代码或执行查询。
已经加载的同 owner 资源跨首页、设置和查询继续复用；身份或代际失效仍撤销资源。

离线桥、确定性测试和隔离浏览器证据分别记录。当前薄 SDK 候选的真实实例更新
与冷加载须另获授权；本批代码与构建成功不代表真实宿主验收通过。

普通设置按声明 group 的首次出现顺序形成独立 fieldset；同一 owner 的各组
仍共用一次保存与精确 CAS。当前合同的 group 是技术标识，没有本地化组标签，
因此单组显示“普通设置”，多组显示“设置组 1/2”；技术标识仅见于详细信息。
