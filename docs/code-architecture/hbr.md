## 1. 归属与范围

独占目录为 `modules/hbr/`，维护模块清单与验证材料。`/ygl hbr` 是建议路由，不另设中文独立触发命令。

目标包括 B 服登录、个人资料、BOX 和高分查询；公共图鉴与人工导入为独立可选能力。账号接口不可用不能用导入结果伪装成同步成功。

禁止修改主体授权表、加密实现、公共展示协议、渲染器、调度器和根包清单。游戏授权转换属于模块，凭据保存及会话所有权属于主体。

## 2. 代码职责

```text
modules/hbr/
  manifest.json          局部静态声明
  module.py              工厂、能力与生命周期
  models.py              游戏账号、资料、风格、BOX、高分
  login.py               登录环节编排及游戏授权状态转换
  capabilities.py        登录、退出、账号查询等处理器
  adapters/
    bilibili_auth.py     经验证的 B 站认证环节
    game_session.py      游戏授权交换，待验证
    account_data.py      资料/BOX/高分，待验证
    catalog.py           带服务器及版本的公共目录
  display.py             业务数据到通用展示文档
  imports.py             仅在开放人工导入时存在
```

## 3. 能力与可用状态

| 建议能力 ID | 内容 | 入口策略 |
| --- | --- | --- |
| account.login/relogin/status/logout | 用户登录会话管理 | 必须命令 |
| account.profile | 已授权游戏个人资料 | 按当前基本设计，必须命令 |
| account.box | 已授权 BOX 查询 | 按当前基本设计，必须命令 |
| account.score | 已授权高分记录 | 按当前基本设计，必须命令 |
| catalog.search | 公共角色/风格/技能检索 | 可选，允许自然语言 |
| box.import | 用户主动导入的持有数据 | 可选，属于个人数据操作，命令入口 |

角色/风格公共资料来源异常不应禁用仍可用的账号资料；账号会话来源不可用不应禁用公共图鉴。授权链路未验证的能力标为不可用或待配置/验证，不注册可正常执行的假入口。

某用户凭据失效仅影响该用户。主体的命令策略和授权范围检查不可由模块替代。

## 4. 登录与主体授权的分工

模块实现待扫码、待确认、B 站认证完成、游戏授权交换、游戏授权可用之间的业务转换。主体分配用户隔离的 LoginSession、代次、截止时间和任务作用域，保存凭据引用及 Grant。

二维码通过主体受控资源与通用 image 块交付，标为私人登录用途；不直接发送消息、不进入 FactDocument 或日志。轮询属于有限时会话工作，交给 TaskScope 管理，不为每个用户建立脱离主体的永久调度循环。

重新登录增加会话代次，旧扫码/交换结果不得写回新会话。只有游戏会话验证完成才提交游戏 Grant 并返回登录成功。B 站网页认证成功不能替代游戏授权成功。

退出先由主体使本地授权和会话失效，再由模块尝试来源支持的撤销；上游撤销失败不能重新激活本地凭据。个人查询与结果提交均带授权版本校验。

登录涉及的网络字段与设备参数仅在受控授权环节使用。所需实际接口、签名和生命周期未验证前，不实现假成功流程。

## 5. 业务数据结构

| 模型 | 语义 |
| --- | --- |
| GameAccountRef | 已验证游戏账号 ID、服务器、授权范围 |
| PlayerProfile | 来源实际存在的昵称、等级/进度、时间 |
| StyleCatalog | 服务器、目录版本、稳定风格 ID、名称、稀有度、排序与素材引用 |
| OwnershipSnapshot | 用户账号、目录版本、持有状态、可选突破、同步完整性和来源 |
| ScoreRecord | 期数/挑战、分数、档位/排名、队伍、更新时间及字段存在性 |

“未持有”与“未知”必须区分。只有完整读取且目录范围明确时才计算完成率；缺失条目不能一律压暗为未持有。未知目录风格单独提示，不能丢弃后宣称完成率准确。

BOX 固定排序由目录版本与稳定键定义；跨版本比较先对齐目录。历史高分仅在来源支持时开放，不用当前结果模拟历史。

## 6. 数据隔离与展示

主体保存 Grant、凭据和登录会话。模块集合建议包括公开 `style_catalog`、私人 `ownership_snapshots`、`profile_snapshots`、`score_snapshots`；集合声明所有权与保留类别。

私人缓存键包含用户、授权账号、Grant revision、服务器和目录/查询版本。同一账号被不同用户授权也不自动共享私人缓存。人工导入与账号同步使用不同来源标记和记录类别。

BOX 映射为 metrics 加 item_grid：风格标题、asset_id、正常/压暗状态及可选角标；主体控制尺寸、分页和排版。模块不提供整图、HTML 或绘图回调。登录二维码是受控素材例外用途，不成为自定义业务卡片通道。

默认私人投递遵循主体政策。用户触发群查询不等于授权公开分享；独立分享能力的字段范围和入口尚需确认。

## 7. 并行边界与未定项

可独立设计目录、模型和展示映射；授权适配器以明确不可用状态保留边界，不假设目标 Bot 接口公开。不访问其他游戏模块。

会话与授权服务接口缺项应反馈主体维护者；本模块不另建凭据数据库。公共目录刷新如需后台任务，应通过主体注册并展示用途；当前不新增未被需求确认的个人订阅类型。

未定项：真实授权链路、接口字段和有效期、素材来源、目录范围、公共能力首版范围、分享及导入规则。模块验证材料只使用脱敏样本，不保存真实二维码、Token 或设备标识。
