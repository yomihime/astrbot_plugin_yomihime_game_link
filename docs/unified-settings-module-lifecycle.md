本批基线为 `64d2996e56742ca0976ef8af5911ff8910fbb9a7`，工作分支为 `feat/unified-settings-module-lifecycle`。本文记录实现合同与分层验收；离线通过不表示已更新真实实例。

## 冻结的安全与兼容合同

公开页面服务由壳捕获已验证的 owner 与 page，再提交闭合的能力/参数信封。管理请求继续使用固定宿主正式管理鉴权，不能从公开查询 proof、asset token 或客户端角色标志得到管理权限。普通配置目录与历史四字段迁移目录分离；读写资源及模块生命周期目标由部署明确授信，不能由扫描到的声明扩权。

解除挂载是新的通用管理操作，采用 SDK 1.7 的版本化合同，保留 1.0–1.6 的已有调用策略、页面单能力映射和配置合同，构建真实 wheel 并同步固定 pin。旧 SDK 1.6 字节保持不变。生命周期操作必须校验精确 owner 和 registry revision，事务前后重新校验授权；失败保留清理归属，不允许 cleanup_pending 实例重新启动。

加密预检仅检测当前注入的 provider/codec，不读取存量凭据、不生成真实主钥、不落盘测试密文。默认保留外部 `YGL_SECRET_KEY`；本批不自动初始化或轮换真实密钥。就绪不代表旧密文可解密、OAuth 有效或 FFLogs 查询成功。

共享 SQLite 及其事务保持不变。解除挂载不删除配置、凭据、缓存、业务数据或代码包。恢复若需要正式重新打开插件页面取得新资源投影，应明确提示，不能复用初次模板的过期授权 URL。

## 页面与配置分层

壳的全局设置只展示 Core 公共字段。模块设置按受审 owner 分组展示普通字段和单独的敏感凭据组件；禁用模块仍可管理，解除挂载后退出活动配置目录。部署保留的恢复政策不等于活动字段读写许可。迁移与启动恢复放在高级维护区，与日常配置目录分开。

普通修改以服务端读取的 revision 作 CAS；冲突保留草稿并要求重读、确认。敏感输入不回填，离开设置或真实身份失效时清除。主题、语言和重复展示 context 不构成新的管理权限，也不应覆盖普通草稿。就绪状态未知时与未就绪一样阻止敏感字段填写；就绪只证明当前加密设施可用，不证明 FFLogs 凭据有效。

通用公开调用信封为 `owner/page/capability_id/parameters`。目标能力须同时属于已登记页面和部署批准的公开能力；局部页面名称相同不能跨 owner。模块负责业务参数及事实语义，Core 与 Host 保留输出预算、隐私、期限和发布前生命周期校验。模块声明、字段目录和资源访问证明均不能扩展授权。

旧 FF14 页面退出业务 renderer 后，只保留到宿主插件列表的定位说明，由正常 monitor 入口重新取得页面投影。它不转发旧授权链接，不跨页面资源根导入，也不自动续期资源凭证。同一模块已加载资产可跨视图复用；真正解除挂载或安全失效后须清理并正式重开。

## 更新与恢复前置条件

从驻留 SDK 1.6 更新至 1.7 必须确认运行时冷加载。停用会清理业务，但不证明 Python 导入缓存已经退出；旧代码仍驻留时不能用上传成功代替运行时校验。需要插件级卸载时，明确保留配置和数据，备份完成后由用户确认停止、启动同一宿主，再在运行中的宿主上传固定候选。冷加载后核对实际文件、pin、初始化及正式调用。

备份包含不透明的配置与一致数据库快照，必须放在有合适访问控制的本地目录；不上传到 PR 或发布包。安全权限及真实主钥初始化另行授权。回退须匹配 SDK 加载方式和数据格式；不能在有并发修改时整库覆盖。模块解除挂载是保留数据的运行时操作，不等同于宿主卸载插件或删除数据。

## 执行顺序与证据层

1. 通用调用、管理目录、加密预检及目标受限生命周期合同。
2. 公共设置组件、壳入口、模块设置与 FF14 Logs/日历；退役旧业务页。
3. 中性模块合同与隔离浏览器验收，冻结后独审及一次适用全量。
4. 同一 Local Test 集中更新与最小真实验收；需要冷加载时集中请求人工停止/启动。
5. 通过质量门槛后推送功能分支并创建面向 master 的草稿 PR。

离线回放、隔离 Host、浏览器模拟、真实实例与真实上游分别记录。缺少 FFLogs 凭据或加密初始化授权时保持未验证，不以保存状态替代 OAuth 验收。日历外部失败如实记录；本批不调用付费模型。

## 当前完成情况与保留限制

REQ-01–07 的源码、相关合同测试与正式资源构建已完成。隔离浏览器使用固定宿主的资源重写与模拟 bridge，覆盖亮暗主题、窄屏、键盘、草稿和焦点保留；已加载模块资产跨过 60 秒后切页没有新增资产或业务请求。模拟失效、解除挂载及迟到结果测试也已执行。这些证据不替代真实宿主鉴权、持久数据或上游查询验收。

最终串行全量报告 1376 项：1360 通过、0 失败、2 错误、14 跳过，没有因模块导入或类初始化而阻塞的方法。两项错误来自既有 Windows 维护入口祖先目录 ACL 检查，安全检查保持拒绝；14 项为既有平台条件跳过。独立终审未留下 Blocker 或 Important。相关页面测试、类型检查、Ruff、构建与正式 ZIP 摘要检查通过；既有格式及 EOF 提示不算本批已经清理。

已在授权的独立宿主完成 SDK 1.6→1.7 安全冷加载、正式 monitor 入口、物品 44091 部分成功及缺项提示、名称市场查询与候选续接。市场请求省略范围，实际采用 Core `cn` 的 China 全区，保留 `all/overview`、服务器名称、来源年龄及非实时限定；这不代表 `global/all` 或真实模型回答已经验收。

普通 Core 区域完成合法保存、读回、旧 revision 拒绝与使用最新 revision 恢复原值，FF14 三个日历字段保持不变。真实冲突提示、页面内生命周期确认与取消焦点恢复已验证。禁用保留模块设置；解除挂载退出查询、设置与样式；恢复使用原受信候选并要求正式重开。只读摘要比较确认配置、240 个持久文件及 33 个非运行态表不变，仅运行意图与日志两表变化。没有执行真实数据库迁移、整库回退或删除数据。

Logs 未配置状态和日历一次上游失败在真实页面如实展示，保留恢复入口，没有伪造空结果或重复查询。FFLogs OAuth、角色查询、存量密文解密、日历活动内容和新版本模型回答均未验证；本批未读取或初始化真实主钥，也未填写真实凭据。加密设施未就绪时，敏感输入在填写前被禁用。

真实宿主还暴露了四处前端适配缺口：bridge 将 CAS 错误压成普通 Error、沙箱不允许原生 confirm、沙箱不允许 iframe 跳转顶层导航，以及刷新按钮原生禁用导致键盘焦点丢失。最小修复保留原授权与 CAS，采用受限页面内确认、明确的宿主菜单重开指引，并让忙碌刷新按钮保留可聚焦节点，以 aria-disabled/aria-busy 与实时准入门禁抑制重复调用；不使用延迟回填焦点，也不修改 sandbox、增加权限或虚构资源续期接口。最后三个前端测试 runner 分别为 91、13、4 项通过，共 108 项，类型检查与构建通过；前述 Python 全量记录对应未改动的后端字节，不把多轮计数累加成新的全量结果。

最后纯前端更新仅替换两份壳 app 资源，已通过真实 monitor 入口重新加载。键盘刷新保留原按钮焦点、输入节点、选区和滚动；约 251 秒后的同模块切页保持两个样式节点，没有新增资产或业务请求。亮暗主题保留未提交输入和选区，跳至正文实际移动焦点并滚动。此轮没有重复查询或配置写入；此前业务与管理证据对应同字节的模块、后端、SDK 和数据库合同，不能称为又执行了一轮新查询。

目前没有新增持久主钥生成器：预检复用已经注入的加密设施，兼容外部 `YGL_SECRET_KEY`。需要初始化或轮换主钥时，操作者必须另行确认安全位置、权限和备份恢复；不要把它放入普通配置、URL 或聊天。未就绪时页面在输入前说明阻塞，而不是降级为明文保存。

共享 SQLite 未拆库，模块代码、活动资源及持久命名空间有明确 owner。解除挂载保留配置、凭据、缓存和业务数据；删除数据是另一个危险操作，没有在本批开放。合成第二模块仅为测试夹具，不进入正式安装包。
