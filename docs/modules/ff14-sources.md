# FF14 来源边界

本页记录 FF14 模块当前声明的外部来源及其职责。来源声明与解析器只证明代码允许访问固定主机和有限路径；不保证服务在线、数据完整、配额可用或真实宿主端到端成功。实现入口见 [`modules/ff14/assembly.json`](../../modules/ff14/assembly.json) 和 [`modules/ff14/features/`](../../modules/ff14/features/)。

| 能力 | 来源 | 职责与边界 |
| --- | --- | --- |
| 市场 | Universalis | 世界、大区目录与行情数据。FF14 模块校验目录关联、请求范围、来源身份和缓存来源；报价代表来源返回的数据，不保证实时可买。 |
| 物品基础资料 | XIVAPI-compatible (`xivapi-v2.xivcdn.com`) | 搜索、名称、描述、物品等级和装备等级。请求使用固定字段、语言和有限分页。 |
| 获取途径与效果补充 | Garland (`garlandtools.cn`) | 仅补充结构化获取途径和属性效果。它不是物品基础资料的自动备用来源；关联缺失或来源不可用时，模块保留基础资料并说明补充不完整。 |
| 公开角色 Logs | FFLogs 国际服与国服 | 两个地区使用各自声明的主机和凭据，不相互借用。模块限制 GraphQL 查询形状、目录投影及结果预算；返回范围必须按实际请求与响应判断。 |
| FFLogs 输出统计 | 未启用 | 当前模块不提供旧 `output` 命令或统计页面；不要把公开角色 Logs 能力视为输出统计已实现。 |
| 活动日历 | Google Calendar 与 iCloud CalDAV 固定 feed | 地区与来源 URL 由模块代码映射，读取有界 ICS，并校验时间、事件和来源身份。来源间的结果分别保留；不能仅凭配置或单次成功声称日历完整或持续新鲜。 |

所有网络请求都经本次模块调用绑定的 `SourceHttp` 能力，并受 Core 的来源声明、资源授权、取消和期限约束。不得从管理页面或通用 HTTP 代理绕过模块边界，不接受任意 URL、header 或 GraphQL 文本。

上游协议、服务、字段、数据及图像的许可彼此独立。项目不随插件包分发上游数据库或图像；新增复制、再分发或衍生使用前，必须核对对应来源的现行条款。代码中使用的有限字段解析不意味着取得上游内容的再分发权。
