## 设计合同

绝境战与零式表格统一六列、同宽对齐，顺序为「副本 / 职业 / 记录版本 / 最高 rDPS（或所选指标）/ 过本次数 / 最佳百分位」。显式筛选的非分组表格保留原五列。重复的逐副本资料片脚注移除；真实缺项、历史未查全及需要用户处理的授权问题保留简短准确提示。

目录 Logs 卡片通常使用现有 Document.width=1240，保持原字号。显示名称超过保守 Unicode 宽度阈值时使用有界1400或1500宽版并加宽副本列，覆盖普通英文完整副本名；此宽版也适用于显式筛选的五列表格。宽度估算仅选择版式，最终仍由生产字体测量和既有绘图预算检查。副本完整名称、职业和普通指标单元格不自动换行、不缩写、不省略；表头通过列宽保持单行。表后使用一个紧凑统一注释区，真实缺项由行内 ERR / — 与简短范围说明区分，不重复列举每个副本的状态或资料片。正常完整记录不增加缺项脚注。超出单行容纳能力的未来名称保留原文，由既有完整文本回退处理，不放大 Core 全局绘图预算。

记录版本属于获选整行的统计分区，不宣称已查明具体击杀发生的小版本，也不是副本开放版本、当前游戏版本或最新记录日期。保留来源 partition ID 和原始分区名称，只从已知、无歧义的包装提取完整版本表达式：`7.0`、`7.05`、`7.51`、`3.55b+`、明确的开放或闭合范围。版本是字符串，不能转浮点或丢失零、字母、加号及范围末端。Echo / 超越之力是规则而非版本；无版本或未知标签保留原来源，已知资料片时显示 `5.x` / `6.x` / `7.x`，否则 `—`。数字 partition ID 不转换成补丁号。

零式在既有目标资料片、零式难度和八人范围内查询全部明确合格分区。标准与非标准均参与，所有 Echo / 超越之力分区提前排除；未知资格不当作非 Echo。不同 partition ID 即使名称相同也分别保留，不按名称或奇偶 ID 推断、合并。`None`、`-1` 与正分区身份不同，旧汇总不得在明确分区失败时顶替；旧筛选缓存不得污染新结果。比较原始 Decimal 百分位，真正同分沿用 zone / encounter / difficulty / partition ID 的稳定升序，不以完成顺序、标准优先或猜测的新版本优先决胜。职业、版本、阵容、rDPS、次数保留同一获胜分区整行，次数不跨分区累加。

零式获胜分区为非标准阵容时，版本前绘制普通字面 `*`，如 `*7.4`、`*3.55b+`、`*7.x`、`*—`；标准不加，未知不假设。表下使用紧凑小字注释区，数据源移到该区，采用实际地区域名；说明“版本为统计分区；次数为该分区过本次数”“最高 rDPS 与最佳百分位可能来自不同场次”。实际有星号才显示“* 非标准阵容”；真实范围未取得才提示部分记录。正常完整图片不展示请求计数、缓存写失败诊断或长实现解释。最底部独立保留现有项目标志及 `Powered by yomihime/astrbot_plugin_yomihime_game_link`，与注释适度分隔。事实与安全诊断保持各自原合同。

绝境分组优先使用游戏数据 ContentFinderCondition（ContentType=28）的 SortKey 降序。通过模块已声明的 xivapi_items 来源、现有托管 HTTP 访问公开 /api/search，仅请求 Name、SortKey、ContentType 原值；不发送玩家身份或成绩。仅唯一、规范化后完全一致的完整副本名可以匹配，FFLogs ID 与游戏表 ID 不混用，不使用简称、模糊匹配或固定七本白名单。新副本只要进入来源目录即可自动参与。当前游戏目录请求 language=chs；英文或其他语言的国际服 FFLogs 全名可能无法完全匹配，此时使用回退顺序，不保证国际服精确新旧排序。

SortKey 是游戏菜单排序，不是精确发布日期或开放补丁证据。元数据仅影响显示顺序，不改变获选成绩、职业、次数、百分位或记录版本。完整成功目录缓存24小时，失败/不完整结果最多缓存60秒；每次最多两页、每页100项、总计最多3秒且受当前剩余工作期限约束，无逐行请求。分页未完不据此声称名字唯一，也不使用不完整目录排序。缓存随模块关闭清除；缓存不持有请求权限对象。

匹配失败、名字歧义、超时、普通上游错误时保留 FFLogs 成绩并回退；权限拒绝、模块撤销和取消仍遵守原生命周期边界。新来源不是必要健康依赖，不修改 required_sources 或 SDK；该来源已在模块 manifest 中声明。

回退顺序使用完整、归属校验通过的 FFLogs 目录，不维护固定副本白名单。每个同名分组以来源资料片列表中最早的规范归属目录出现位置为锚点，再按来源资料片列表顺序展示；同资料片内保持该锚点目录顺序。跨版本重发目录、最佳成绩来自更早/更晚版本、查询预算与查询结果均不改变该锚点。缺少资料片顺序证据的分组按稳定目录顺序放到末尾。未匹配游戏目录的分组排在可匹配分组之后，互相之间保持回退顺序。

回退是来源目录惯例下的新旧排序，并非已验证的发布日期排序：资料片列表假定按来源通常的新到旧顺序返回；同资料片目录不能证明精确补丁先后。非规范归属别名不作为锚点。目录缺项或来源改变顺序时，不能保证真实开放次序；不以 zone/encounter 数字 ID 或获选成绩时期猜测。

Core 通用 Table 使用当前主题 panel / panel_alt 两色交替整行背景，表头使用 panel_alt，每张表重新计数。浅色、深色主题及其他模块表格共用该行为；FF14 百分位颜色、字体、logo、SDK 声明及指标取值规则不变。
