# Noto Sans CJK SC Regular

© 2014-2021 Adobe (http://www.adobe.com/).

The source repository retains the original, unmodified
`NotoSansCJKsc-Regular.otf` from Noto Sans CJK version 2.004 (Sans2.004),
face index 0, as an offline reference for reproducible rendering. No subsetting,
renaming or other font modification has been performed.

The lightweight plugin release includes this notice and `OFL.txt`, but does not
include the OTF file. Core manages a separate persistent copy obtained from the
fixed trusted resources or an administrator upload of those exact pinned bytes.
The font identity, size and digest below apply to that copy as well as the
repository reference; the presence of this notice does not mean a usable font
has already been downloaded or installed.

Each round tries each source at most once, serially, within one 45-second total
deadline. Each source has at most 15 seconds, including connection and reading,
with connection and read-inactivity limits of 5 seconds each. Redirects,
environment proxies and content decompression are disabled. These fixed HTTPS
URLs cannot be replaced through configuration or upload input. The TUNA mirror
may update its file; any response with a different size or digest is rejected
before trying the next source. Every source must match the exact pinned identity
above before atomic publication. A valid persistent copy skips downloading.

Download failure codes distinguish connection, timeout, HTTP/encoding, length,
digest and local publication failures without exposing response bodies or raw
exceptions. The final attempted failure is reported if all sources fail;
publication failure stops the round because another identical download cannot
repair local storage. Existing system-font and text fallbacks remain available.
The management page's manual download link keeps the original pinned upstream
URL. Source reachability still requires separate verification on each host.
